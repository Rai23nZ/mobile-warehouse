Аварийная выгрузка отчёта

Собирает те же два CSV, что и кнопка «Завершить и скачать отчёт», но в обход приложения.

Инструмент только читает. Проверка не закрывается, данные с сервера не удаляются — после выгрузки их можно забрать ещё раз или доработать смену обычным способом.

Файл открывается прямо с диска. Если браузер запретит запросы со страницы, открытой как file://, положите его рядом с приложением и откройте по адресу /tools/rescue.html.

Куда идти

Базы у этих адресов разные. Проверка, созданная на одном, на другом не существует. Какой адрес был у ведущего — видно в консоли браузера на его устройстве: localStorage.getItem('wh_api_base'). Если неизвестен — переберите по очереди.

Код забыт? На телефоне любого проверяющего он лежит в localStorage: ключ wh_sync_queue_<КОД>_<номер> либо JSON.parse(localStorage.wh_session_v4).session.code. Без отладчика: в наряде нажать «Завершить» — код напечатан в окне подтверждения, затем «Отмена».

Достаётся из базы одним запросом — см. ниже. Оставьте пустым, если вместо него используете ключ ведущего.

Обменивается на токен через POST /session/<код>/reclaim. Работает только если на сервере развёрнута версия worker.js с этой точкой доступа.

Как достать токен из базы

Московская машина — по SSH, в каталоге службы:

sqlite3 warehouse.db "SELECT code, store, lead_name, created_at, lead_token FROM sessions ORDER BY created_at DESC;"

Cloudflare — панель, D1 SQLite Database → warehouse → Console:

SELECT code, store, lead_name, created_at, lead_token FROM sessions ORDER BY created_at DESC;
Данные брошенной проверки живут ограниченное время: подчистка сносит смены старше 36 часов. Выгружайте до истечения срока.
